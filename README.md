# 🇳🇵 Nepal Flood Impact Dashboard

An interactive Power BI dashboard analyzing the impact of flooding across districts of Nepal.

## 📊 Dashboard Overview

This dashboard provides a visual analysis of:

- 👥 People affected by district
- 💀 Deaths
- 🔎 Missing persons
- 🩹 Injured and rescued people
- 🗺️ Affected districts across Nepal
- 🏗️ Infrastructure damage
- 📈 Overall impact distribution
- 🎯 Rescue progress

## 🛠️ Tools & Skills

- Power BI
- Data Visualization
- Data Analysis
- Dashboard Design
- Data Storytelling

## 📌 Data Source

**Nepal Disaster Risk Reduction and Management Authority (NDRRMA)**

**Data Date:** 28 August 2026

## 🎯 Project Objective

The objective of this project is to transform disaster-impact data into an interactive and visually meaningful dashboard that helps users understand the scale and distribution of flood impacts across Nepal.
